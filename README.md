# 国家对战模拟器 | National Battle Simulator v2.0

一款回合制战略游戏，玩家扮演国家领导者，通过建设城市、发展经济、组建军队、进行战争等手段来壮大自己的国家。

## 项目文档

- [设计文档](design.md) - 详细的游戏设计方案和指南
- [任务清单](issues.md) - 开发任务和功能规划

## 快速开始

1. 打开 `index.html` 文件在浏览器中运行
2. 点击"新游戏"按钮开始游戏
3. 建造建筑、招募军队，制定策略获取胜利

**Q: 油车单位如何使用？**  
A: 油车需要同时拥有研究中心和油车厂才能招募。将油车开入敌方领地后停留2回合，即可占领该领地并有机会生成特殊建筑。每回合只能招募一辆油车，且油车不能进入已有建筑的格子。

**Q: 魔法兵的特殊能力有哪些？**  
A: 魔法兵需要同时拥有研究中心、图书馆和魔法学院才能招募。它有50%概率触发魔法刀使攻击力翻倍并获得反伤或破甲效果。此外，魔法兵血量低于50%时每回合会损失10%血量但攻击力增加100%，血量低于10%时有一次复活机会。

**Q: 如何获得魔法学院？**  
A: 魔法学院无法直接建造，只能通过油车占领敌方领地时有1%的概率获得。这是一座非常珍贵的建筑，可以提供50金币/回合的收入，并给周围友军提供攻击和防御加成。
